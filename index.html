Как установить клавиатуру

Пошаговое руководство для разных операционных систем.

💻

Для ПК (Windows / macOS)

  1. Установите программу Keyman Desktop.
  2. Скачайте файл pomere_xugnune.kmp выше.
  3. Дважды кликните по скачанному файлу .kmp.
  4. Подтвердите установку, и раскладка появится в системном трее Keyman.
📱

Для смартфонов (Android / iOS)

  1. Установите приложение Keyman из Google Play или App Store.
  2. Скачайте файл pomere_xugnune.kmp на телефон.
  3. Откройте файл через Keyman приложение или добавьте его через меню «Install Keyboard».
  4. Включите клавиатуру в настройках телефона.
